Run a weekly financial checkup by executing these commands and providing actionable insights:

1. `ynab sync` - refresh data
2. `ynab budget` - budget status and planned expenses
3. `ynab recent -n 30` - last 30 transactions
4. `ynab transfers --days 7` - recent transfers
5. `ynab plan` - planned expense status

Summarize with:
- Week's spending highlights by category
- Any uncategorized or unapproved transactions that need attention
- Planned expenses coming due and their funding status
- Suggested actions (categories to fund, transactions to review, etc.)
