---
description: Monthly spending vs budget report
---

Show spending for the current month compared to budget targets:

1. Call `sync_data()` to refresh
2. Call `spending_report()` for category-by-category spending vs budget
3. Call `funding_status()` for target vs average spend recommendations

Summarize which categories are over budget, which are on track, and which have room. Flag any categories where spending consistently exceeds the target (patterns, not one-off months). If a category is significantly over, suggest which flexible discretionary categories could offset it (for example dining out, hobbies, or entertainment).
